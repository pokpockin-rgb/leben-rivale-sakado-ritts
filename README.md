# レーベンリヴァーレ坂戸リッツ｜施工会社選定ヒアリング

GitHub Pagesで公開するHTMLプレゼンテーションです。

## 構成

- `index.html`：GitHub Pagesの公開入口
- `assets/`：プレゼン内で使用する画像
- `.nojekyll`：GitHub Pagesで静的ファイルとして配信するための設定

## 更新方法

1. `index.html` または `assets/` 内のファイルを更新
2. `main` ブランチへコミット
3. 数十秒〜数分後にGitHub Pagesへ自動反映
