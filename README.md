# レーベンリヴァーレ坂戸リッツ 大規模修繕工事

施工会社選定ヒアリング用 HTML プレゼンテーションです。`index.html` は POWER EDIT v17 完成版です。

## 操作

- `← / →`、`PageUp / PageDown`、スペース：前後のページ
- `Home / End`：先頭・末尾
- `一覧` または `O`：スライド一覧
- `メモ` または `N`：プレゼンターノート
- `全画面` または `F`：全画面表示
- `EDIT`：ブラウザ編集モード
- 編集パネル：要素追加、スタイル、MASTER、ガイド、ページテンプレート、保存、PRESENT、PDF / PRINT

## 構成

- 32ページ
- 本編想定：37分10秒
- 40分枠に対して2分50秒の質疑・進行バッファ
- ページごとのプレゼンターノートは `index.html` 内に埋め込み
- 参照資料・不一致・本番前確認事項は `SOURCES_AND_CHECKS.md` に整理

## 更新方法

`EDIT` を押すと、文字・画像・図形・ページ・共通デザインをブラウザ上で編集できます。画像は `assets/` の相対パスで参照しています。

- `Ctrl+S`：上書き保存。ブラウザが直接保存に非対応の場合はHTMLを書き出します。
- `Ctrl+Shift+S`：名前を付けて保存
- `index_editable_v17_COMPLETE.html`：v17完成版の名前付きコピー
